# Запуск без своего сервера: Supabase + Vercel + Business-бот

Как это работает:

```
Telegram ──(каждое сообщение, сразу)──► Vercel: /api/telegram/webhook ──► Supabase (база)
Supabase pg_cron ──(раз в минуту)──► Vercel: /api/cron/tick ──► агенты: разбор, заявки,
                                                                  ответы, диагноз, обучение,
                                                                  эскалации, сводка в 09:00
Браузер ──► Vercel: сайт + /api
```

- **Своего сервера нет.** Vercel запускает код по запросу, Supabase хранит
  данные и будит агентов по расписанию.
- **Telegram не заблокирует аккаунт**: сообщения приходят через официальный
  Bot API. Личка служебного аккаунта — через Telegram Business, группы — через
  бота, добавленного в них. Бот только читает и клиентам ничего не пишет.
- **Telethon больше не работает постоянно.** Он нужен один раз — загрузить
  историю за месяц с вашего компьютера (шаг 9).

Команды ниже — в PowerShell, из папки `backend`, если не сказано иначе.

## 0. Что нужно

| Что | Зачем | Цена |
|---|---|---|
| Supabase (у вас есть) | база, расписание, резервные копии | ваш тариф |
| Vercel | сайт и функции | **Pro, ~$20/мес**: бесплатный Hobby — только для некоммерческого использования |
| Бот у @BotFather (можно ваш @sbsupportoffice_bot) | приём сообщений | бесплатно |
| Telegram Premium на служебном аккаунте | Telegram Business: бот видит личку | ~$5/мес |
| Ключ Anthropic | агенты | по расходу |

## 1. Строка подключения Supabase

Supabase → ваш проект → **Connect** → **Transaction pooler** (порт 6543).
Получится `postgresql://postgres.xxxx:[ПАРОЛЬ]@aws-0-…pooler.supabase.com:6543/postgres`.
Для «Довода» в начале допишите `+asyncpg`:

```
postgresql+asyncpg://postgres.xxxx:ПАРОЛЬ@aws-0-…pooler.supabase.com:6543/postgres
```

## 2. Таблицы и перенос данных — один раз, с компьютера

Остановите локальный «Довод» (Ctrl+C). В `backend\.env` временно поставьте
`DATABASE_URL=` строкой из шага 1 и выполните:

```powershell
python -m app.setup_db --from-sqlite dovod.db
```

Создадутся таблицы, включится защита (RLS), перенесутся чаты, отели, задачи,
сотрудники и пароли. Без `--from-sqlite` — пустая база.

Если пароля руководителя нет или он забыт:

```powershell
python -m app.users password bekzod
```

## 3. Бот

В @BotFather → `/mybots` → ваш бот → **Bot Settings**:

1. **Group Privacy → Turn off** — иначе в группах бот видит только команды.
2. **Business Mode → Turn on** — иначе его нельзя подключить к Telegram Business.

## 4. Vercel

1. vercel.com → **Add New → Project** → репозиторий `dovod` из GitHub.
   Root Directory — корень репозитория, Framework — **Other**. Остальное
   Vercel возьмёт из `vercel.json`.
2. **Environment Variables** (для Production):

| Переменная | Значение |
|---|---|
| `DATABASE_URL` | строка из шага 1 |
| `BOT_TOKEN` | токен бота |
| `ANTHROPIC_API_KEY` | ключ Anthropic |
| `SESSION_SECRET` | случайная строка — подпись входа на сайт |
| `CRON_SECRET` | случайная строка — пароль расписания |
| `MANAGER_NAME` | Бекзод |
| `TIMEZONE` | Asia/Tashkent |

   Случайную строку даст: `python -c "import secrets; print(secrets.token_hex(32))"`.
   `SESSION_SECRET` не меняйте потом — иначе всех разлогинит.

3. **Deploy.** Адрес сайта будет вида `https://dovod-xxx.vercel.app` — откройте,
   войдите логином и паролем.

## 5. Подключить бота к Vercel

На компьютере (нужен только `BOT_TOKEN` в `.env`):

```powershell
python -m app.bot.webhook set https://dovod-xxx.vercel.app
python -m app.bot.webhook info
```

Если на Vercel задан свой `WEBHOOK_SECRET`, впишите его и в локальный `.env`.

## 6. Расписание в Supabase

Supabase → **SQL Editor** → вставьте `deploy/supabase-cron.sql`, замените
адрес сайта и `CRON_SECRET` на свои → **Run**. Через 2–3 минуты проверьте
(запросы — в конце того же файла): ответы 200 и `{"ok":true,…}`.

## 7. Telegram Business — личка с отелями

На телефоне служебного аккаунта (нужен Premium):
**Настройки → Telegram для бизнеса → Чат-боты** → введите имя бота.

- Доступ: **«Все чаты, кроме…»** — или выберите нужные.
- Права «Отвечать на сообщения» и прочие **выключите**: боту достаточно читать.

## 8. Группы

Добавьте бота в каждую рабочую группу (23 группы, «Добавить участника»). Если
бот уже был в группе до шага 3 — удалите и добавьте снова, иначе режим
приватности для этой группы не сменится.

## 9. История за месяц — один раз

Бот видит только новые сообщения. Старые разово загружает Telethon с вашего
компьютера — `DATABASE_URL` в `.env` пока указывает на Supabase:

```powershell
python -m app.chats history 30
```

После этого Telethon больше не нужен. Верните в `.env` локальную базу, если
продолжите что-то пробовать на компьютере.

## 10. Проверка

1. Напишите в рабочую группу «тест: не приходят брони».
2. Через минуту оно появится во «Входящих» на сайте.
3. «Команда» → «Чаты»: написано «Сообщения присылает Telegram сразу», есть
   кнопка «Разобрать сейчас».

## Обновление

Пуш в ветку, подключённую к Vercel, — и Vercel пересоберёт сайт сам. Если в
обновлении новые таблицы или колонки — один раз `python -m app.setup_db` с
`DATABASE_URL` Supabase.

## Если не работает

| Что видно | Что делать |
|---|---|
| Сообщения не появляются | `python -m app.bot.webhook info`: адрес и «Последняя ошибка» |
| В группе бот молчит в базе | Privacy не выключен — шаг 3, затем бота удалить и добавить снова |
| Личка не приходит | Шаг 7: бот подключён в «Чат-ботах», чат не в исключениях |
| Во «Входящих» пусто, сообщения есть | Расписание: запросы в конце `deploy/supabase-cron.sql` |
| `SESSION_SECRET не задан` | шаг 4, переменная в Vercel, затем Redeploy |
| Чат появился выключенным | его выключил руководитель — включить в «Команда» → «Чаты» |
